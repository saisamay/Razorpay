## 2. EXACT PRODUCTION ALGORITHM SPECIFICATION

### A. Point Estimator (Unchanged)
$$\hat{\tau} = \frac{1}{N_{\text{eligible}}} \left[ \frac{1}{p} \sum_{i \in T, R_i=1} \frac{Y_i}{\hat{\pi}_{1i}} - \frac{1}{1-p} \sum_{i \in C, R_i=1} \frac{Y_i}{\hat{\pi}_{0i}} \right]$$

### B. Cluster IPW Totals
For every canonical assignment-unit cluster $k$:
$$\hat{T}_k^{\text{obs}} = \sum_{i \in k, R_i=1} \frac{Y_i}{\hat{\pi}_{ai}}$$
where $\hat{\pi}_{1i} = \sigma(X_i^T w_T)$ for Treatment cases, and $\hat{\pi}_{0i} = \sigma(X_i^T w_C)$ for Control cases.
Clusters with zero observed outcomes ($M_k = 0$) contribute $\hat{T}_k^{\text{obs}} = 0$.

### C. Candidate B Variance Calculation
$$\widehat{V}_B = \sum_{k: A_k=1} \frac{(\hat{T}_k^{\text{obs}})^2}{p^2} + \sum_{k: A_k=0} \frac{(\hat{T}_k^{\text{obs}})^2}{(1-p)^2}$$

$$\text{SE} = \frac{\sqrt{\widehat{V}_B}}{N_{\text{eligible}}}$$

$$\text{CI}_{95\%} = \hat{\tau} \pm 1.96 \cdot \text{SE}$$
